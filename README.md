# Vroma Cut

Vromaで記録したGPXとマーク情報をもとに、動画からお気に入りの場面を手軽に切り出せるmacOSアプリです。
撮影中に付けたマークを手掛かりに候補を表示し、動画を見ながら残したい範囲を調整できます。

**マーク情報がなくても、動画だけを読み込み、指定した箇所を再エンコードせずに切り出せます。**
映像と音声の圧縮済みデータをコピーするため、再圧縮による画質や音質の劣化はありません。
再生可能な境界に合わせるため、実際に保存する範囲は指定範囲より広がる場合があります。

## 主な機能

- VromaのGPXとマークCSVから切り出し候補を作成
- タイムラインで範囲を調整し、複数の候補を選択、結合、削除
- カメラとGPXの時計のずれを補正
- 対応する分割録画を通して再生し、境界をまたぐ範囲を1本のMP4に保存
- 撮影日時を維持し、書き出し後に映像と音声の内容を照合
- 書き出し中も次の動画を編集し、待ち行列へ追加

原本の動画、GPX、マークCSVは変更しません。
編集状態はアプリ終了時に破棄されます。

## ビルドして使う

ソースコードを公開しています。
ビルド済みアプリやインストーラーは配布せず、利用するMacでビルドします。

必要な環境はmacOS 15以降、Apple Silicon、Swift 6を含むXcodeです。
Xcodeを一度起動して初期設定を完了し、Settings → Locations → Command Line Toolsで使用するXcodeを選んでください。
Intel MacとUniversalビルドは未検証です。

リポジトリを取得し、ルートディレクトリで実行します。

```sh
git clone https://github.com/tsuyukimakoto/vroma_cut.git
cd vroma_cut
./scripts/build.sh
open '.build/Vroma Cut.app'
```

初回はFFmpeg 8.0.3の公式ソースをダウンロードし、固定したSHA-256を確認して必要なライブラリをビルドします。
同じビルド条件での再実行ではライブラリを再利用します。
Homebrew、Node.js、FFmpegコマンドのインストールはアプリのビルドや利用に不要です。
生成するアプリは手元での利用向けのad-hoc署名で、公証は行いません。
詳細は[ビルドとテスト](docs/BUILDING.md)を参照してください。

## 使い始める

1. 「動画フォルダを選ぶ」で撮影動画のあるフォルダを選ぶ
2. Vromaの記録を使う場合は「GPXを選ぶ」でGPXを選ぶ。同じフォルダの同名のマークCSV（例：`trip.gpx`と`trip.marks.csv`）を自動で読み込む
3. マークから作られた候補を確認する。マークがない場合は、動画上の残したい位置で「この位置にマークを追加」を押す
4. 候補の開始点と終了点を調整し、「動画を切り出す」で範囲と保存先を確認して書き出す

GPXと動画はどちらから読み込んでも構いません。
別名のマークCSVは「マークCSVを追加…」から読み込めます。
詳しい操作は[使い方](docs/USAGE.md)を参照してください。

## 対応範囲

現在の書き出しはHEVC映像1トラックとAAC音声1トラック、および対応可能なタイムコードを対象にしています。
任意の動画形式には対応していません。
内部の撮影日時を取得できない動画や、未対応の追加トラックを持つ動画は書き出しを停止します。
カメラ独自のメタデータは別ファイルへ退避しますが、原本の復元やメーカーソフトでの再利用は保証しません。

[出力仕様と制限](docs/EXPORT.md)に詳細を記載しています。
