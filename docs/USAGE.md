# Vroma Cutの使い方

## 基本操作

1. 「GPXを選ぶ」でGPXを選択する。同じフォルダの同名 `.marks.csv` を自動で読み込む。別名のCSVは左側の「マークCSVを追加…」から選べる
2. 「動画フォルダを選ぶ」で動画の保存先を選択する。GPXとは別のフォルダでよく、読み込む順序も問わない
3. 最初のマークに対応する候補の開始位置から確認する。番号付きのピン、または「前のマーク」「次のマーク」で移動する
4. 青緑の帯が書き出し対象、濃い帯が編集中の候補。両端の「始」「終」をドラッグするか、「現在位置を開始に」「現在位置を終了に」で希望範囲を変更する。タイムライン右下の、読み込みメッセージと同じ行にあるズームのスライダーとスクロールで表示範囲を変える。「全体」で動画全体の表示に戻る
5. タイムライン上部の「この位置にマークを追加」で候補を追加する。同じ操作パネルで再生位置・開始点・終了点を選び、秒単位で微調整する
6. 「動画を切り出す」で選択中の動画だけを確認し、保存先を選んで「この動画を書き出す」を押す。再圧縮しないため、実際の範囲は希望範囲より広がることがある
7. 書き出し中に次の動画を選んで編集し、確認後に「書き出し待ちに追加」を押す。同じ保存先にも順に書き出せる
編集状態はアプリを開いている間だけ保持し、終了すると破棄します。起動時は直接編集画面を開き、プロジェクト書類の選択や保存確認は行いません。編集はUndoでき、原本のGPXやCSVは変更しません。

動画フォルダとGPXの選択場所は別々に記憶し、次回もそれぞれの場所から選べます。
前回のフォルダがなくなっていたら、存在する親フォルダまで戻ります。ホームフォルダ、各ユーザーフォルダ、`/Volumes/ボリューム名`より上には戻りません。
ボリューム自体がないなど、境界まで探しても開ける場所がない場合はホームを開きます。記憶した場所は新しい選択を確定するまで保持します。

動画と操作エリアの境界をドラッグして、操作エリアの高さを調整できます。
ウィンドウのリサイズでは操作エリアの高さを保ち、動画エリアを伸縮させます。動画が最低限の高さに収まらなくなる場合だけ操作エリアも縮めます。
ウィンドウの位置・サイズと動画エリアの高さを自動で記録し、次回起動時と動画読込時に復元します。
保存時の画面がない場合や画面からはみ出す場合は、現在の画面内に収めます。通常の最小サイズを確保できない小さな画面では、操作部全体をスクロールして利用できます。
「ウィンドウ」→「初期サイズ・表示位置をリセット」で、現在の画面の中央に初期サイズで戻し、動画と操作エリアの配分も初期化できます。
重ならない候補は同じ行に並び、時間範囲が重なる候補だけ段を分けます。
タイムラインの帯をクリックして選択し、⌘クリックで追加・解除、Shiftクリックで連続範囲を選択します。
上部の「削除」またはDeleteキーで候補を削除し、「1つにまとめる」で選択した複数範囲を結合できます。
チェックボックスは使わず、タイムラインに残した候補をその動画の書き出し対象にします。
候補が多く縦にスクロールする場合も、削除・結合ボタンはタイムラインの上に残ります。
動画直下の中央に現在の再生位置を表示します。右端の「?」ボタンで選択・削除・サイズ調整などの操作ヘルプを開けます。タイムラインの時刻目盛りと編集領域は横線で区切り、時刻目盛りの上でもクリックして再生位置を移動できます。
スペースキーで再生・一時停止できます。
動画をマウスで操作する必要はなく、文字入力中やダイアログ表示中のスペースキーは再生操作に使いません。

保存先が未選択の間は「選ぶ…」が青く表示され、書き出しボタンは押せません。保存先を選ぶと書き出しボタンが青くなります。
書き出し対象・範囲・撮影日時は確認時点で固定され、その後の編集は待機中・実行中の書き出しへ反映されません。
アプリを開いている間、保存先は動画ごとに保持し、まだ保存先を指定していない動画では前回の保存先を初期値にします。
既存の出力は上書きせず、同名なら連番を付けます。
上部の「書き出し一覧」で実行中・待機中・完了・失敗を確認でき、待機中の項目も個別にキャンセルできます。
完了時に編集画面からFinderへ自動で切り替えず、一覧の「保存先を開く」から出力を確認します。
待ち行列は開いている編集画面内で実行し、画面を閉じると未完了分をキャンセルします。

「動画とGPXの時刻を合わせる…」では、進める／戻す方向と、年・月・日・時間・分・秒を入力します。
選択中の動画のカメラ日時を基準に年月を計算し、補正後の日時を確認できます。
算出した同じ時刻差をすべての動画と今後追加する動画に適用します。
未編集のマーク由来候補は補正に追従し、動画上で追加したマークと編集済み候補は位置を保ちます。
時刻合わせ後に未確認の候補はオレンジの枠で表示します。候補を選ぶと操作パネルに未確認の件数と「確認済みにする」が表示されるので、範囲を確認してから押してください。未確認の候補が残っている動画は書き出せません。

内部日時が得られない動画は再生と手動編集ができますが、書き出しは停止します。


## マーク情報がない動画

GPXやマークCSVを読み込まず、動画フォルダだけを選んで利用できます。
動画を選び、残したい場面で「この位置にマークを追加」を押してから、開始点と終了点を調整します。
「動画を切り出す」で実際の出力範囲と保存先を確認してください。
映像と音声は再エンコードせずコピーします。
撮影日時を取得できない素材は、手動編集できても書き出せません。
